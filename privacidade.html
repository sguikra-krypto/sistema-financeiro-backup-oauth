Política de Privacidade

Aplicativo: Sistema Financeiro Backup

Última atualização: 20/11/2026

1. Finalidade

Esta integração é utilizada para armazenar cópias de segurança criptografadas de um sistema financeiro de uso privado, mediante autorização do titular da conta.

2. Acesso ao Google Drive

O aplicativo utiliza a permissão drive.file, limitada aos arquivos criados ou explicitamente autorizados para esta integração.

3. Armazenamento e proteção

Os backups são criptografados antes do envio ao Google Drive. Os arquivos armazenados podem incluir dados financeiros e documentos protegidos por essa criptografia.

4. Compartilhamento

A integração não comercializa dados nem compartilha voluntariamente os conteúdos dos backups com terceiros. Os arquivos criptografados são armazenados no Google Drive, sujeito às condições de serviço do Google.

5. Controle e revogação

O titular pode revogar o acesso concedido à integração nas configurações de segurança da sua Conta Google. A revogação impede novos acessos autorizados, mas não implica exclusão automática dos arquivos já armazenados.

6. Uso dos dados das APIs do Google

O uso das informações recebidas das APIs do Google observa a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
