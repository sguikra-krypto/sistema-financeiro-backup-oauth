Sistema Financeiro Backup

Esta é uma integração privada destinada à realização de cópias de segurança do Sistema Financeiro Automatizado.

A integração utiliza a API do Google Drive, por meio da ferramenta rclone, para armazenar backups criptografados em uma conta autorizada pelo usuário.

O acesso ao Google Drive utiliza a permissão drive.file, limitada aos arquivos criados ou explicitamente autorizados para o aplicativo.

Os arquivos financeiros são criptografados antes do envio. Esta página não permite consultar o sistema, visualizar backups ou acessar informações financeiras.
